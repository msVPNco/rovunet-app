# Local 0.1.4-preview.3 — HTML buttons and page chrome hotfix

The owner reported that HTML buttons/internal pages stopped responding. The previous
navigation test opened pages directly from C# and missed the actual entry path.
A new HTML-click reproduction failed at toolbar Settings with a callback timeout.
WebView2 serializes callbacks; entering DialogWindow.ShowDialog's nested DispatcherFrame
inside WebMessageReceived prevented subsequent messages from completing.

The handler now validates/copies the message and posts its existing action to the WPF
dispatcher, returning from WebView2 before any modal page loop starts. Existing command,
origin, enabled-state and typed-value checks stay intact. Reference:
https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/threading-model#reentrancy

All DialogWindow page toolbars are projected as a single compact HTML header: back,
title, and save/actions on the opposite side. In RTL the row follows the page direction.
It stays at the top while scrolling. The previous generic stack projection put these
controls on separate rows. Import TabControl now has selectable HTML tabs and only the
selected body is shown, instead of projecting all TabItem bodies without their headers.

`--ui-html-navigation30 REPORT` enters settings, nested protocol creation, card editing,
subscription, About and resolver pages through actual DOM clicks. It sends a second
message while the modal page is open, saves an edited synthetic profile from the toolbar,
checks the compact back/save row and switches the QR import tab. No owner data, proxy,
network or external link is used. ROVUNET_HTML30_LANGUAGE and ROVUNET_HTML30_THEME select
the four-language/three-theme fixture variants; they affect this test only.

This is an urgent UI-only local hotfix. Protocol-handshake work and the corrected
1000 ms green threshold remain in HANDSHAKE30 continuation; no UDP completion is claimed
by this hotfix. SKIN29/public 0.1.3 bytes stay immutable. Final receipt records the
exact packaged-byte checks; native reentrancy scope is not inferred from fixture counts.
