# Local 0.1.4-preview.6

Mahsa keeps its canonical raw URL. If that request fails, the app tries GitHub's official Contents API for the same repository, branch and file with the raw media type and a User-Agent. Both requests keep the selected proxy route, standard TLS validation, no automatic redirects, bounded response size and a combined 25-second acquisition deadline. A bad cipher/schema is never retried against a different source. AES ASCII key/IV, deduplication, unsupported/TLS rejection, review before Add and managed-source URL hiding are unchanged. Complete validated updates replace only that Mahsa collection; partial batches are add-only; failed acquisition/decode/validation/save preserves previous data.

Slipstream Simple/E2E opens results before certificate acquisition. The cancellable session prepares trust once before starting any candidate Agent. Delayed certificate retrieval has a translated stage label and Stop; HTTP/setup failure is a visible global error, not a false failed tunnel measurement for each resolver. DNS compatibility proofs remain separate and retry resumes unfinished tunnel work. Back/close cancels pending preparation. Existing TLS, source/account/item/domain binding and different-pin protection remain mandatory.

Focused regression entry points are `--ui-feed32` and `--ui-scanstart32`, using synthetic feeds/certificates/DNS and pointer input in the app's owned WebView. They do not write the owner's private store or run remote Slipstream. Exact-package reports and receipt hashes accompany the local delivery; development results must not be described as final-package execution.

The live Mahsa failure on the owner's network occurred before the raw host's certificate callback. The official API returned the same encrypted file over valid HTTPS; the fixed production client decoded eight unique links, accepted six and rejected two requiring insecure TLS. These source counts can change. The rejected entries were not made insecure to obtain a pass. See the separate sanitized live receipt for assembly hash and time.

Public 0.1.3 Beta and preview.5 delivery bytes remain immutable. Manager's conditional private-preview review of preview.5 does not approve preview.6. Panel review is pending; live Slipstream testing waits for the owner's server upgrade. Slipstream SSH backend traversal, deployed trust/status, owner installation/data retention and the earlier native/TUN/SCM/reboot acceptance gates remain separate.
